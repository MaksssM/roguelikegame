# RoguelikeGame

Low-poly 3D roguelike (Godot 4.7): survive, level up, combine elements.

- Modular weapons: delivery × pattern × effect (~400 combos), upgrades, evolutions
- Elemental reactions with combo multiplier, adaptive enemies, relics, shrines, pickups
- Procedural seed worlds, daily runs, world codes to share
- Biomes (meadow, desert, snow, swamp, volcano, crystals), bosses, pause, minimap
- UI languages: English, Українська, Русский

## Run

Open `project.godot` in Godot 4.7 and press Play (main scene: `scenes/main.tscn`).

## Controls

- WASD — move, mouse — camera, Space — jump
- Ctrl — slide downhill, Tab — stats, C — copy world code, Esc — pause
